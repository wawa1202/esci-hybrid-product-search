# 点击式项目面板与场景教程

用户已选择同时改善教学说明和图形操作。目标：普通使用不输入 PowerShell 命令，能体验搜索、读真实报告、依次建索引/训练/评估，知道每一步在做什么。

方案：使用笔记本已有 Tkinter 和 pythonw，提供本地桌面面板；搜索继续使用现有网页。相比新增远程任务 API，无需开放训练入口到网络；相比只改文字，也解决了变量与命令复制问题。主搜索算法和评估口径不变。

1. 新建 `tests/test_workbench.py`，验证报告转换、路径范围、实验依赖、任务拒绝并行及退出状态。
2. 新建 `src/product_search/workbench.py`：资源发现、实验路径/CLI 参数、子进程运行、日志事件，拒绝覆盖，后台执行。
3. 新建 `src/product_search/desktop.py`：四个侧栏页面、按钮、真实报告表格、学习说明、日志。关闭时停止自己启动的服务；有实验在跑时先提示用户选择，不结束其他进程。
4. 新建根目录 `打开项目.cmd`，双击使用项目 pythonw；缺依赖时显示可理解的错误。
5. 重写 `docs/USAGE.md` 为场景教学，保留原命令在 `docs/COMMANDS.md`，更新 README 和 FILE-GUIDE。
6. 验证：定向测试、全量回归、Tk 窗口构建/切页、真实发布包启动与搜索、已有报告显示、新实验按钮参数。不开跑完整训练，不消费真实 test。

线程约束：Tk 控件只在主线程更新，子进程输出经队列传回。在线服务与实验任务分开管理。错误保留日志和失败输出目录。实验面板只提供 dev，test 仍留最终验收流程。

源码目录不是 Git 仓库，不创建分支或提交。
