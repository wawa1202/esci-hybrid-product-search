# 商品搜索项目补齐计划

目标：沿用已有 ESCI 数据和接口，完成可复现的本地商品搜索闭环。只使用公开数据；本次运行 dev，保留 test 不用于调参。

1. 保存既有源码副本；在项目虚拟环境安装依赖。
2. 为数值指标、向量索引、融合、排序、服务建立边界测试。
3. 补齐带哈希校验的发布产物、固定版本 MiniLM、分块精确向量搜索和 RRF。
4. 补齐无标签泄漏的特征、LightGBM 按查询分组训练、兼容性校验和预测。
5. 分开评估固定人工候选集排序与商品库召回；实现配对比较、错误分析和延迟统计。
6. 补齐命令行、HTTP 服务、演示页面和启动入口。
7. 使用现有 dev 数据跑真实索引、训练、validation 评估和接口；记录实际结果与未验证范围。
8. 提供按文件划分的职责、调用关系与复现说明。

并行边界：评估基础模块、BM25/文本修复、ranking 子包分别独立；主线负责产物、向量、编排、服务及集成。最终统一验证。

约束：不把未标注商品当作 I；离线训练可读 labels.sqlite，线上只读 catalog；服务默认仅监听本机；不声称 dev 指标代表完整商品库或线上业务效果。
